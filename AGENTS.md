# Правила работы с Изохроной

- Выкладывай готовые результаты каждой задачи (код, схемы, картинки и отчёты) в её ветку на GitHub. Планы и отчёты оформляй в Markdown с картинками, которые видны прямо на странице.
- В конце давай прямые ссылки на GitHub. Ссылки на локальные файлы Codex и облачной среды у владельца не открываются.
