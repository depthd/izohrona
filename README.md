# Изохрона

Генератор соревновательных карт для CS2. Открыл страницу, нажал кнопку, получил
готовую карту с балансом, укрытиями и файлом для Hammer.

## Как пользоваться

Открыть в браузере **`builds/izohrona_v142.html`**.

| кнопка | что делает |
|---|---|
| Сгенерировать карту | новая карта |
| Перекатить только укрытия | та же планировка, другие ящики |
| 🚶 Пройтись по карте | карта от первого лица прямо в браузере: ходить, прыгать, приседать, как в игре. Нужен интернет |
| ⬇ Скачать .vmap | целая карта сразу для Hammer CS2, вместе с радаром |
| ⬇ Скачать .vmf | старый способ, через импорт в Hammer |
| Номер карты → копировать | по номеру открывается ровно эта карта. Удобно писать «на карте № … вот тут» |

В прогулке: `W A S D` — идти, мышь — смотреть, пробел — прыжок, `C` — присесть,
`Shift` — шагом, `V` — полёт сквозь стены (колесо — скорость), `1`/`2` — спавн T/CT,
`3`/`4` — плент A/B, `M` — большая карта, щелчок по ней переносит туда, `P` —
скопировать номер карты и точку, где стоишь, `Esc` — пауза (чувствительность мыши,
качество картинки), ещё раз `Esc` — выход. В углу — радар с местом, где стоишь.

## Где что лежит

| папка | что там |
|---|---|
| `src/` | исходники продукта, разложенные по частям. Править здесь |
| `core/` | запись `.vmap`, перевод `.vmf → .vmap`, ядро из вещей (черновик) |
| `tools/` | сборка и приборы проверки |
| `data/` | образец `.vmap` из Hammer, размеры текстур, эталонные карты |
| `docs/SPRAVKA_CS2.md` | справка по новому Hammer и Source 2: размеры игрока, материалы, сущности, свет |
| `proby/` | пробы, отданные на проверку |
| `builds/arhiv/`, `docs/arhiv/` | старые версии и старые документы |
| `CLAUDE.md` | правила работы и все решения |

## Сборка и проверки

```bash
node tools/sobrat.js
```

```bash
bash tools/priyomka.sh builds/izohrona_v142.html 3
```

| проверка | что ловит |
|---|---|
| `tools/priyomka.sh` | гейт: проходы, крюки, спавны, браши |
| `tools/smoke.js` | все кнопки и ползунки живые |
| `tools/proba_vmap.js` | кнопка `.vmap` даёт целый правильный файл |
| `tools/proba_nomer.js` | номер открывает ту же карту байт в байт |
| `tools/proba_progulka.js` | прогулка: пол держит, стены не пускают, прыжок как в игре, перенос по карте |
| `tools/zamer_progulki.js` | сколько миллисекунд рисуется кадр прогулки |
| `tools/vmapcheck.py` | целостность `.vmap` |
